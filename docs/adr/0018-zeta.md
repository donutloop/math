# ADR 0018: zeta(x)

**Status:** Accepted
**Date:** 2026-09-10

## Context

Special functions were missing the Riemann zeta, fundamental to analytic
number theory and series evaluation.

## Decision

Add `zeta(x)` for x > 1 using a 2000-term series plus an Euler-Maclaurin
first-order tail correction (n^(1-x)/(x-1) + 1/(2 n^x)). Domain error for
x <= 1.

## Consequences

- zeta(2)=1.644934 (pi^2/6), zeta(3)=1.202056 (Apery).
- Verified by tolerance unit tests (calc/zeta_test.go).
