# ADR 0037: bell(n)

**Status:** Accepted
**Date:** 2026-09-10

## Context

The combinatorics set lacked Bell numbers (set partitions).

## Decision

Add `bell(n)` with the recurrence B(i)=sum_{k<i} choose(i-1,k)*B(k),
using the existing choose helper. Domain error for n < 0.

## Consequences

- bell(0)=1, bell(3)=5, bell(4)=15, bell(5)=52.
- Verified through the parser-level verify harness.
