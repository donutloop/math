# ADR 0048: eta(x)

**Status:** Accepted
**Date:** 2026-09-10

## Context

zeta(x) existed but the alternating Dirichlet eta function was missing.

## Decision

Add `eta(x)` = (1 - 2^(1-x)) * zeta(x), with the analytic limit eta(1)=ln2
to avoid zeta's pole.

## Consequences

- eta(1)=ln2 (0.6931), eta(2)=pi^2/12 (0.8225).
- Verified by tolerance unit test (calc/eta_test.go).
